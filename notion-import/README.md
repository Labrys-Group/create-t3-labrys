# Notion Import Folder

This folder contains company-wide documentation policies and standards that should be imported into Notion.

## Files Included

- **documentation-standards.md** - Complete guide on documentation requirements, principles, and PR approval criteria for all Labrys projects

## How to Import

These files can be imported into Notion using Notion's markdown import feature:

1. In Notion, navigate to the workspace where you want to import the documentation
2. Click "Import" in the sidebar
3. Select "Markdown & CSV"
4. Upload the markdown files from this folder
5. Notion will create pages based on the markdown structure

## Note

These files contain general documentation policies that apply across all projects and are not specific to any particular codebase or tool.
